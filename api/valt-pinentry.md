# valt/pinentry

The valt pinentry program for passphrase input.

## Functions

### useValtPinEntry()

Sets PINENTRY_PROGRAM to the path of the valt-pinentry binary.

### disableValtPinEntry()

Unsets PINENTRY_PROGRAM, restoring the default pinentry behavior.
