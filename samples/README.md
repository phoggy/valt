# Sample paper key

The inputs for the sample paper key on valt's web site (`assets/sample-paper-key.pdf`), which valt's pages hook
(`bin/valt-pages-hook`) generates from them whenever they, the template or its fonts change.

- `sample.key`, `sample.pub`: a throwaway key pair made for the sample. Its passphrase was random and never kept, so the
  key cannot be used: it is only there to be printed.
- `key-info.json`: the sample's key info. The people, numbers and addresses are fictional, and its `watermark` value
  stamps every page SAMPLE.
